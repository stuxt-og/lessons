============================================================
  COFFEE HOUSE — LANDING PAGE
============================================================

Односторінковий лендінг для кав'ярні, створений з використанням
HTML5, CSS3 та Bootstrap 5.0.2. Адаптивний дизайн, тепла
коричнево-кремова палітра, плавні анімації та сучасна структура.

------------------------------------------------------------
  1. ДЕМО
------------------------------------------------------------

Лендінг містить такі секції:

  Navbar   - Фіксоване навігаційне меню з бургер-кнопкою
  Hero     - Головний банер із заголовком, описом та кнопкою CTA
  Menu     - Три картки з напоями (Еспресо, Капучино, Лате)
  About    - Блок "Про нас" із зображенням та переліком переваг
  Contact  - Форма зворотного зв'язку (ім'я, email, повідомлення)
  Footer   - Копірайт та контактна інформація

------------------------------------------------------------
  5. ВСТАНОВЛЕННЯ ТА ЗАПУСК
------------------------------------------------------------

  Варіант 1: Локальний запуск
  ------------------------------
  1. Клонуйте репозиторій або завантажте архів:

       git clone https://github.com/your-username/coffee-house-landing.git
       cd coffee-house-landing

  2. Переконайтеся, що всі залежності на місці:

       static/lib/reset.css
       static/lib/bootstrap/bootstrap-5.0.2-dist/css/bootstrap.min.css
       static/lib/bootstrap/bootstrap-5.0.2-dist/js/bootstrap.bundle.min.js

  3. Відкрийте index.html у браузері:
       - Двічі клікніть на файл, або
       - Використайте Live Server (VS Code extension)


  Варіант 2: Локальний сервер (рекомендовано)
  ---------------------------------------------
     Python 3:      python -m http.server 8000
     Node.js:       npx http-server
     PHP:           php -S localhost:8000

  Потім перейдіть на http://localhost:8000


------------------------------------------------------------
  6. КАСТОМІЗАЦІЯ
------------------------------------------------------------

  Кольорова палітра
  -------------------
  Темно-коричневий  #3e2723  - Заголовки, navbar, footer
  Коричневий        #6f4e37  - Кнопки, акценти
  Світло-коричневий #5d4037  - Hover-стани
  Бежевий           #f5e6d3  - Фон hero та contact
  Кремовий          #fdfaf7  - Фон секції меню

  Як змінити основні кольори
  -----------------------------
  Відредагуйте значення у css/style.css, наприклад:

       :root {
           --color-primary: #6f4e37;
           --color-dark:    #3e2723;
           --color-light:   #f5e6d3;
       }

  Як додати нову картку в меню
  ------------------------------
  Скопіюйте блок .col-md-4 у секції #menu в index.html та змініть:
       - src зображення
       - назву напою
       - опис
       - ціну

  Як змінити зображення
  ------------------------
  Усі зображення завантажуються з Unsplash через URL.
  Щоб використовувати локальні файли:
       1. Створіть папку images/
       2. Додайте зображення
       3. Замініть src="https://..." на src="images/your-image.jpg"
